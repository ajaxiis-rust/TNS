## Задачи (префикс T-18, файл плана при регистрации — 18-dictionaries.md)

**T-18-01. Детектор тональности (апгрейд detectors_mood.json)**
- Словарь владельца: `mood_vectors` (5 осей с valence), `modifiers` (отрицания, усилители, ослабители), `signals` (ASCII-смайлы, тянущиеся гласные, CAPS, `?!`).
- Правится: `detectors_mood.json` (веса вместо плоского списка), слой в `turn/prepath.go` для модификаторов.
- Канон: D-13 «отрицание — отдельной леммой "не"», п.4 «вектор отрицания не ловит — первый голос словарь» (наш `negation_multiplier: -0.75`).
- Потребители: гипотеза настроения в Пилу (prepath), категория emotion разбора книг.
- Проверка: `go test ./...`, гейт лемм, манифест.

**T-18-02. Детектор сарказма**
- Словарь владельца: `patterns` (n-граммы 2–4 слова), `coefficients` (позиции 1.5/1.3, кавычки ×3.5, контраст-пары), порог 1.0.
- Правится: новый `sarcasm.json` в пакете + детектор в prepath.
- Правило интеграции: пробитый порог сарказма обнуляет скор флирта (зависимость с T-18-03).
- Потребители: настроение в Пилу, цензор (издёвка ≠ прямой негатив).

**T-18-03. Объединение erotic.json с детектором флирта/эротики**
- Один источник, два контура: книги (W-22: веса 1–3, severity 1–4 → 1/2/2/3) и чат (D-11: скоринг 0–1, пороги flirt 0.75 / erotica 1.0).
- Словарь владельца: 4 категории severity, множитель второго лица 1.45, ролевые ремарки +0.45, анти-медицина ×0.25, обнуление по сарказму.
- Формат-донор: `erotic.json` уже умеет фразы (IMP9) — добавляем слой `severity` на элемент.
- Правится: `erotic.json`, контур разбора книг (веса), контур чата (скоринг).
- Потребитель будущий (вне объёма): NPC-карты (идиолект, речевые маски литбазы).
- Проверка: разбор тестового чанка 18+ → severity; ложные «горячий чай»/«болит грудь» не срабатывают (анти-медицина).

**T-18-04. Влитие KAINE-пластов в категории и детекторы**
- Стейджинг `TNS-GOLD/dict-staging-20261122/`: настроение 113, эмоции 69, действия 67 лемм (нормализованы `tns65-lemmaru`).
- Правится: `detectors_mood.json` (настроение), ось emotion разбора (эмоции), `action_dramatic.json` (действия).
- Гейт: каждая лемма лемматизируется в себя, вес 1–3, дубликаты убраны, манифест.
