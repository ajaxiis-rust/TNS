## 4. Эксперимент: имена в синопсисе (вопрос владельца 23.11)

Вопрос: тянет ли библейское имя (например, «Каин») вектор синопсиса к
нарративу об этом сюжете — не получим ли сразу «историю Каина и Авеля»?

Факт о пуле: `base.ru.db` анонимизирован полностью — собственных имён нет,
заглавные токены только роли («Герой», «Община», «Правитель», «Божество»);
поиск «Каин», «Авель», «Моисей» даёт ноль нарративов. Обезличенная арка
сюжета есть: id212 «Суд и испытание · 076» (два брата, отвергнутый дар,
зависть, убийство, изгнание, отметка).

Пять проб против полного пула (производственный путь, сохранённые векторы):

| проба | топ-1 | результат |
|---|---|---|
| сюжет Каина и Авеля с именами | 0.641 | id212 — та самая арка |
| тот же сюжет без имён | 0.733 | id212, увереннее на +0.09 |
| детектив, герой по имени Каин | 0.558 | топ-3 тот же, что без имени |
| тот же детектив без имени | 0.577 | идентичный топ-3 |
| кот по кличке Каин | 0.472 | нерелевантная полоса |

Выводы эксперимента:

1. Арку находит смысл, имя — шум: «Каин»/«Авель» — токены без соответствия
   в анонимизированном пуле, они разбавляют вектор (0.733 → 0.641).
2. Имя не перехватывает ранжирование: у детектива-Каина топ-3 совпал с
   безымянным, косинусы ниже на 0.02–0.03. След семантики имени виден лишь
   на 4-м месте («Предательство · 020», 0.535 — нерелевантная полоса).
3. Порог 0.65 отрабатывает: детективная анкета (0.56–0.58) — неродной
   жанр, якорь назначится принудительно с пометкой forced; сюжет без имён
   (0.733) проходит уверенно. Пограничный случай: сюжет с именами (0.641)
   уходит чуть ниже порога — якорь верный (id212), но с флагом forced.
4. Для лемм-буста: лемма «каин» в пуле встречается ноль раз — словарный
   контур в подборе якоря не нашёл бы ничего; вектор находит арку смыслом.

## Вывод и рекомендация

1. Подбор якоря на живом BGE-M3 работает: 8/8 на золотом наборе в обоих
   путях, дискриминация топ-1/топ-2 устойчивая.
2. Порог 0.50 (текущий дефолт `defaultMatchThreshold`) пропускает часть
   нерелевантных синопсисов как «близкий якорь» без пометки forced:
   рецепт 0.505, погода 0.516. Позитивы при 0.50 не страдают.
3. Свободный коридор между полосами: 0.516–0.745. Рекомендуемый порог —
   **0.65** (запас ~0.13 в обе стороны). Консервативный вариант 0.70 —
   ближе к позитивам, повышает риск ложных forced.
4. Порог уже конфигурируется (`match_threshold` в config.yaml, 0 → 0.5).
   Смена дефолта в `anchor.go` — решение владельца.
5. Лемм-добавка (`anchorLemmaBoost` 0.15 в реестре 21.11) в коде
   отсутствует — измерять нечего. Решение владельца 23.11: **снята с
   реестра** (строка в журнале LEDGER). Код «Шага 2» сохранён на закладке
   `dry/16-distillation-full` (точка 080bf11); возврат — по факту живых
   ошибок подбора (зазор топ-1/топ-2 < 0.05 при неверном якоре).
