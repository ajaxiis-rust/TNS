# TNS65 — Словарь терминов (технический)

Правило: в документах и разговоре — только эти точные термины; выдуманные слова и метафоры для технических состояний запрещены; новый термин вносится сюда, а не в текст мимо словаря. Имена подсистем (Ткач, Челнок, Пила и др.) — код-имена ролей; их переименование запрещено. Определения даны инженерным языком: класс сущности, исполнитель (код или модель), интерфейс, хранение, ограничения. Пополнение — по ходу написания карточек пунктов.

Формат определения: **Термин** — класс сущности. Назначение. Исполнитель / ввод-вывод / ограничения. (ссылки на пункты парадигмы)

## Контур и время
- **Живой ход** — операционный контур обработки реплики. Полный цикл «игрок отправил реплику» → «мир ответил»: мост Telegram → фасад :8000 → конвейер хода → ответ игроку. Класс: рантайм-пайплайн. Слово «бой» запрещено. (шапка парадигмы)
- **Мастерская** — фоновый контур вне живого хода. Окно: паузы и ночь. Задачи: ковка заготовок, расчёты, подготовка артефактов. Исполнители: Гефест, Паганель, Пифия, авто-критик. (шапка, п.7)
- **Пауза** — интервал молчания игрока, измеряется сервером. Ступени ≥10 мин / >1 ч / >3 ч открывают работы соответствующей тяжести. (п.7)
- **Ночь (окно 8 часов)** — пауза > 8 ч после закрытия главы. Гарантированное окно полной ковки и подготовки пробуждения. (п.7, п.13)
- **Сессия** — игровой сеанс. Создаётся только событием прихода игрока; движок сессии не создаёт. (п.13)
- **Глава** — лог сессии без правок. Рамка главы — игровой день от пробуждения до сна. Глава не генерируется отдельно — она фиксируется по факту прохождения. (п.13)
- **Пробуждение** — утренний пакет открытия главы. Состав: 3 последних хода, статы, портрет, положение. Готовится в мастерской заранее; запасной путь — генерация в живом ходе. (п.13)

## Роли
- **Ткач** — генеративный слот живого хода. Исполнитель: LLM (внешний API или локальная модель). Назначение: уникальная и эмоциональная проза сцены. Рутина из банков через Ткача не проходит. Слот сменный, требования к кандидату — п.14. (п.1)
- **Челнок** — поставщик рутины. Исполнитель: код. Операция: выбор готовой фразы из банка по ключу сцены. Генерация текста отсутствует. (п.1, п.3)
- **Селектор** (бывший Драматург) — планировщик хода. Исполнитель: код. Функции: выбор типа действия (квест через NPC / происшествие / иное), держит стоп-краны, приоритет реплики игрока, подача держащего крючка сценарной рамки. (п.11, п.21)
- **Пила** — диспетчер глубины. Исполнитель: код. Вход: пилообразная эмоциональная переменная хода (корреляция с настроением ответов и юнгианским психотипом). Выход: рекомендация «Ткач или Челнок». Статус: советник; решение — за Селектором. Пик → Ткач, ровный участок → Челнок. (п.6)
- **Паганель** — картограф мира. Исполнитель: код + внешний LLM. Область: земля, места, пути, известность. Резидент мастерской, не агент живого хода. (п.16)
- **Пифия** — предсказатель реплик. Исполнитель: код + мастерская (Гефест по заказу). Область: профиль игрока. Выходные артефакты: карта игрока, гороскоп. (п.17)
- **Гефест** — исполнитель фоновой сборки. Исполнитель: код + модели в мастерской. Назначение: банки, переплавка оседшего, гороскопы. **Forge** — имя подсистемы в коде TNS35; Гефест — роль этой подсистемы. (п.18)
- **Авто-критик** — функция Гефеста. Исполнитель: малая модель, оффлайн/ночь. Назначение: ревью заготовок и оседания, выносит уровень доверия. (п.10)
- **Редактор** — внешняя модель, батчевый режим. Назначение: грамматика и пунктуация глав, краткое содержание главы. (п.13)
- **Цензор** — три употребления, различать по месту: (1) словарная цензура живого хода — автомат для всего живого (п.12); (2) цензор при ковке — разовая очистка пула банка на выходе ковки (п.4, п.18); (3) проверка правок Редактора — код: выравнивание слов 1:1, вставки/удаления запрещены (п.13).
- **Толмач** — модуль перевода. Убран из живого хода (миграция 65). Остался разовой операцией сборки языкового пакета. (п.4)
- **Летописец / Картограф / Штурман** — режимы походов Паганеля: политика выхода за границы описанной земли. Выбор — отдельным полем анкеты (п.13), из жанров не выводится. Игроку режим назван функционально (земля мира), код-имя роли в UI не показывается. (п.16)
- **Станок** — пайплайн встроенных моделей. Стадии/эндпоинты: :5001 — генерация (3B q4, ~5.6 ток/с), :5002 — эмбеддинги BGE-M3. (п.5, п.8, п.14)

## Материалы
- **Банк** — пул готовых артефактов, хранимых в базе данных (чтение из БД / запись в БД). Два подтипа: рутина — готовые фразы; драма — формы. Функция страховки: Ткач превышает порог ожидания → Челнок выдаёт запасную версию из пула. (п.1–3)
- **Рутина** — повторяемое поведение. Выдаётся одинаково, без дрейфа модели. (п.3)
- **Форма** — шаблон драмы в банке. Поля: ситуация + намерение + конфликт + эмоциональная функция. Слоты заполняет Ткач. (п.2)
- **Арка** — сюжетный шаблон из base.db с токенами-слотами ([NPCname] и др.). (basically-arcs)
- **Сид** — базовое наполнение движка (base.db). Собирается из книг-источников. (п.20, basically-arcs)
- **Ковка** (синонимы: **варка**, **запекание**) — обработка артефакта встроенной моделью с сохранением результата в базу данных. «Варка» — исторический синоним; «запекание» — вариант того же процесса в контуре Паганеля (земля, атлас). (п.7, п.18)
- **Заготовка** — артефакт, полученный ковкой заранее (сцена, NPC, локация). Деактивирована до крючка. Ревью и цензура — до деактивации. (п.7)
- **Пачка** — стартовый штат персонажей мира: 96 заготовок (психотипы × сословия). Генерируется при рождении мира под строй и экономику. (п.20)
- **Пряжа** — сырьё текстового вывода. Три источника: книга, станок, осевшее. (п.10)
- **Оседание** — конвейер переработки удачных живых сцен в банки. Стадии: проверки живого хода → очистка от фактов → дедуп → авто-критик → уровень доверия. (п.10)
- **Полотно тайн** — пул тайн, полученный ковкой заранее (переодетый принц, беглый каторжник). Назначение тайны — отложенное, при драматургической выгоде. (п.12)
- **Ружьё (чеховское)** — зарегистрированный показанный элемент. Селектор сначала ищет незаряженное ружьё, потом вводит новый. (п.12)
- **Труппа** — подсистема управления персонажами. NPC — актёры одной Труппы. Рождение без истории, память реакций, отложенная тайна. (п.12)

## Данные и базы
- **base.db** — база движка. Расположение: папка движка. Права: read-only для живого хода. Содержимое: базовые нарративы — глобальные сценарии книги. (п.20, п.21)
- **literary.db** — база мира. Расположение: папка мира. Содержимое: точечные заготовки (имена, время, стиль, нюансы) + оседание. Пополняется Forge. (п.10, п.20)
- **world(name).db** — оперативная база мира. Содержимое: вся игра (коллизии, события, пачка). Живой ход пишет только сюда; читает её и банки literary.db. При расхождении приоритет — мир. (п.20)
- **Вектор смысла** — эмбеддинг реплики (:5002). Семантическая близость = расстояние точек в смысловом пространстве, независимо от языка. (п.8)
- **Вектор судьбы** — структурная запись траектории NPC вне орбиты игрока. Поля: домен, направление, сила, срок. Не путать с вектором смысла. (п.7)
- **Карта игрока** — долговременный профиль игрока (Пифия). Поля: психотип, настроение, интересы, привычки. Накопление: ночами. Срок жизни: месяцы. (п.17)
- **Гороскоп** — краткосрочный сценарный прогноз (Пифия). Поля: ветки ответа, прогноз Пилы, темы ковки. Срок жизни: до смены темы. (п.17)
- **Якорь (сценарный)** — глобальный сценарий книги: нарратив из base.db. Старт — ближайший к синопсису. Смена невидима игроку. (п.21)
- **Дрейф** — числовое расхождение вектора общего намерения по главам с якорем. Измеряется ночью в конце главы. Механика без LLM. (п.21)
- **Заявка книги** — короткий замысел игрока (1–3 предложения). Критерий отбора и якорь сверки пути книги. Не план действий: мир игрока к заявке не ведёт. (п.13)

## Механизмы
- **Стоп-кран** — гейт записи в мир. До подтверждения предварительный путь только читает и готовит. (п.9, п.11)
- **Предвыбор** — шаг конвейера: выбор банки или преднабор промпта Ткача до подтверждения смысла. (п.9)
- **Биндер слотов** — подстановка конкретных лиц в токены арок на предвыборе. Исполнитель: код без LLM. Вход: теги Труппы/пачки. Склонение: лемматизатор. Срок привязки: сцена или глава. (п.9)
- **Лемматизатор пакета** — детерминированный словарный сервис языкового пакета (русский — pymorphy3). Латентность: миллисекунды на реплику. (п.14)
- **Языковой пакет** — сменный слой. Состав: лемматизатор + лексикон намерений + запрет-списки + словарные детекторы (времени, настроения). Первый пакет — русский. (п.4, п.14)
- **Глубокий разбор** — один дешёвый вызов LLM на первую реплику главы. Выход JSON: намерение / план / предчувствие / незакрытая тема, каждое с цитатой. (п.13)
- **Стриминговая подкладка** — инкрементальная выдача сцены. Мгновенные заготовки подкладываются, пока Ткач генерирует; ожидание скрыто от игрока. (п.11)
- **Эстафета** — передача напряжения следующему носителю по связям после смещения лица мира. Мир нельзя выиграть, застрелив злодея. (п.19)
- **Лицо мира** — NPC, олицетворяющий сопротивление мира. Поля: архетип, личный мотив, калибр давления. (п.19)
- **Порог смерти** — падение здоровья героя до 2% (рабочее значение). Действие: гарантированная сцена прощания. До порога мир смерть не навязывает. (п.12)
- **Лайк / дизлайк** — сигналы игрока. Лайк: поправки литературных параметров (±15%, шаг 0.02) и сигнал оседания. Дизлайк: перевыбор/регенерация по эскалации. (п.10)
- **Дайджест** — сводка игроку (главы, книга). Сводка мастерской — отдельный термин, не «дайджест». (шапка)
- **Анкета** — форма рождения мира. Смысловое ядро — четыре поля: синопсис, описание мира, рождение героя, цензура 16+/18+. Полный состав анкеты UI — 14 полей: заголовок, описание, синопсис, пролог, язык, режим походов, жанры, правила, социальный строй, экономические модификаторы, магия, рождение героя, isekai, цензура. (п.13)
- **Пролог** — поле анкеты: короткая предыстория или вступительная сцена, подаётся при старте книги. (п.13)
- **Isekai** — поле анкеты: переигровка в том же мире, мир-который-помнит. (п.13)
- **Прорисовка карты** — игроковое имя картографа; код-имя (Паганель) в UI не показывается. Карта мира дорисовывается по мере путешествий героя. (п.16, часть I)
- **Граф отношений** — игроковое окно: связи между персонажами; строится движком из социального графа. Игроку-писателю — контроль нитей, игроку-подростку — подсказка. (п.15, часть I)
- **Админ-зона UI** — разделы интерфейса станка, доступные владельцу и недоступные игроку: миры, конфигурация мира, роли, провайдеры, модели, дашборд, граф, консоль наполнения, настройки. (часть I)
- **Синопсис** — поле анкеты: чем книга началась и закончится. Якорь арки героя с двумя концами сразу. (п.13)
- **Эпилог** — завершение книги. Единственная глава чистого авторства игрока. Содержит авторскую разметку пиков. (п.13)
- **Вести** — запаздывающие известия дальнего круга. Срок доставки в мире: недели. (п.7)
