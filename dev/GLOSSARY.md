# TNS65 — Словарь терминов (технический)

Правило: в документах и разговоре — только эти точные термины; выдуманные слова и метафоры для технических состояний запрещены; новый термин вносится сюда, а не в текст мимо словаря. Имена подсистем (Ткач, Челнок, Пила и др.) — код-имена ролей; их переименование запрещено. Определения даны инженерным языком: класс сущности, исполнитель (код или модель), интерфейс, хранение, ограничения.

Схема записи: термин (не больше двух слов, замороженные составные — целиком) — суть одним предложением — кодовый идентификатор — запрещённые синонимы — ссылка на пункт канона. Машиночитаемая таблица `dev/GLOSSARY-TERMS.tsv` генерируется из якорей (`GLOSSARY.md`, этот файл, `fine/04-spec/00-glossary.md`): `cd engine && bash scripts/glossary-terms.sh`; руками таблица не правится.
