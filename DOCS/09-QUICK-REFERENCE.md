## 2. Три правила (дословно)

1. **Задача:** «Пиши свою книгу просто играя».
2. **Критерий фичи:** текст книги интереснее, ярче и литературно сильнее для постороннего читателя, который не знает автора.
3. **Правило исполнителя:** каждый гейт называет исполнителя — код или модель; человек-владелец в операционном контуре запрещён.

## 4. Три базы

| База | Пишет | Читает живой ход | Отвечает на вопрос |
|---|---|---|---|
| base.db | разработчик (сборка) | read-only | какие истории умеет станок |
| literary.db | Гефест + оседание | да | из какой пряжи сцены |
| world(name).db | движок + игрок | да (основная) | что случилось в мире |

Правила: одна таблица — один писатель; literary.db в живом ходе не меняется; при расхождении мир главнее банков.

## 5. Частые ошибки и последствия

| Заблуждение | Как правильно | Последствие ошибки |
|---|---|---|
| вектор судьбы = вектор смысла | нет: судьбы — траектория NPC (п.7); смысла — `:5002` (п.8) | путаница механизмов, неверная запись в базе |
| заявка книги = план действий | нет: критерий отбора; книга может уйти — это сюжет | Селектор и Пила тянут игрока к финалу, «рука мира» в книге |
| дайджест мастерской | нет: дайджест — только игроку; сводка мастерской — «сводка» | термин перестаёт различать два адресата |
| пила решает, Ткач или банк | нет: пила советует, решает Селектор | дублирование решений, обход стоп-кранов |
| владелец утверждает в операционном контуре | нет: он архитектор; распоряжение — право, не обязанность | человек встаёт в контур, гейт без исполнителя |
| 10-минутная пауза = генерация сцены | нет: только механика; сцена — 30–60 с, шаги длиннее | сцена обрывается возвратом игрока |
| рутина оседает в банки | нет: оседают только полные живые сцены | банк забивается дублями своей же рутины |
| literary.db пишет Паганель | нет: Паганель пишет только world(name).db | нарушение права записи, порча банков |
| Hermes качает модели сам | нет: только по явному запросу владельца | неконтролируемая загрузка, смена слоя без распоряжения |
| мистика вырезается цензурой | нет: тег `mystic`, управляется настройками мира | из мира исчезает целый класс драматургии |
| порог смерти 2% — канон | рабочее значение (помечать, T6) | число принимают за догму, его нельзя пересмотреть |
| все числа в каноне — догмы | часть — рабочие значения; маркировка «канон / рабочее» | спор о цифрах вместо сути механики |
| «варка» и «ковка» — разное | «ковка» — слово процесса; «варка» — исторический синоним | мнимое расхождение терминов в тексте |
