# 11 — Атлас: миры, карта и граф отношений

> Экран «Атлас»: список миров, рождение нового мира в окне и две большие вкладки — карта и граф отношений. Данные только читаются из баз мира; пишут Атлас лишь явные действия игрока (рождение, переключение, удаление, ковка книги).

## 1. Состав экрана

Сверху вниз:

1. **«Миры»** — сетка карточек. Первая карточка всегда пустая: **«Создать мир»** с плюсом. За ней идут существующие миры: название, метка «Активен», число сущностей и сессий, действия «Начать новую жизнь», «Переключить мир» (у неактивного), «Удалить мир», «Играть сейчас».
2. **«Карта / Граф отношений»** — одна секция с двумя вкладками. Она занимает всю оставшуюся высоту вкладки Атласа: canvas растягивается по размеру панели, а не живёт в окне фиксированной высоты.
3. Два модальных окна, скрытых по умолчанию: анкета нового мира и мастер новой жизни.

Кнопка «Создать мир» открывает анкету в окне. Это единственный способ рождения мира из интерфейса; отдельной формы на странице больше нет.

## 2. Окно «Новый мир»

Поля те же, что были в анкете на странице, и порядок сохранён:

| Блок | Поля |
| --- | --- |
| Главное | название мира, адрес мира (`slug`, латиница, автозаполняется из названия), «О чём история» (1–3 предложения) |
| Жанры | восемь частых жанров чипами, «Ещё жанры» — полный список группами |
| Фанфик | галочка «Фанфик — нужна книга-источник»; книгу выбирают в отдельном окне с полки или импортом txt/fb2 |
| Мир | строй мира, режим походов, язык мира, возрастной рейтинг |
| «Ещё» | описание мира, пролог, правила мира (по строке «название: описание»), магия, рождение героя, экономика |

Поведение окна:

- закрывается крестиком, клавишей Esc и кликом по затемнённому фону;
- фокус при открытии ставится в первое поле, при закрытии возвращается на карточку, которая открыла окно;
- ошибки полей показываются у самих полей, общая ошибка — над кнопкой «Создать мир»;
- после успешного рождения окно закрывается, форма очищается, карточка нового мира появляется в сетке, а движок сразу кует книгу (`POST /api/atlas/worlds/forge`; без модели приходит предупреждение).

Мастер новой жизни («Начать новую жизнь» в карточке мира) устроен так же: отдельное окно, Esc и фон закрывают, после успеха окно закрывается.

Если галочка «Фанфик» включена, а книга не выбрана, проверка формы открывает окно выбора книги поверх анкеты; Esc закрывает сначала его.

## 3. Вкладки «Карта» и «Граф отношений»

| Вкладка | Что рисует | Источник |
| --- | --- | --- |
| Карта | места (известные — заливкой, неизвестные — контуром), пунктирные пути между ними, кольцо вокруг положения героя | `GET /api/atlas/worlds/map?world=<slug>` |
| Граф отношений | персонажи по кругу и связи между ними с подписью отношения | `GET /api/atlas/worlds/graph?world=<slug>` |

Активный мир берётся из `GET /api/atlas/worlds` (`active`); если активного нет, показывается первый мир списка.

Рендер:

- canvas растянут на 100% ширины и высоты панели, внутреннее разрешение учитывает `devicePixelRatio`;
- при изменении размера окна и панели срабатывает `ResizeObserver`, карта и граф перерисовываются;
- цвета берутся из переменных темы (`--card`, `--text`, `--brass-2`, `--line-strong`, `--ok`), поэтому светлая и тёмная темы выглядят согласованно;
- при смене темы canvas перерисовывается;
- на вкладке рисуется только видимая панель: скрытый canvas имеет нулевой размер, поэтому рендер запускается при переключении вкладки.

Пустые состояния: «Известных мест пока нет.» на карте и «Связей пока нет.» в графе. Сообщение о состоянии (например, «Карта дорисовывается по мере путешествий героя.») висит поверх canvas в левом нижнем углу.

## 4. Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/atlas/worlds` | список миров и активный слаг |
| GET | `/api/atlas/worlds/map?world=<slug>` | места, пути, герой, кольца |
| GET | `/api/atlas/worlds/graph?world=<slug>` | персонажи и связи |
| GET | `/api/atlas/birth` | канонические перечни анкеты (жанры, строи, походы, рейтинги, языки) |
| POST | `/api/atlas/worlds/birth` | рождение мира по анкете |
| POST | `/api/atlas/worlds/active` | переключение активного мира |
| POST | `/api/atlas/worlds/replay` | новая жизнь в том же мире |
| POST | `/api/atlas/worlds/forge` | ковка книги после рождения |
| DELETE | `/api/atlas/worlds/delete?world=<slug>&confirm=<slug>` | удаление мира |

Все чтения идут через `db.OpenReaderAs`/`OpenWriterAs` по правилам ядра; Атлас не пишет в `literary.db` и не меняет данные мира, кроме перечисленных действий.

## 5. Ограничения

- Карта не масштабируется и не прокручивается: помещаются все известные места мира сразу.
- Граф раскладывается кольцом без силовой укладки; подписи — имена из `characters.name`. Если имя пустое, узел остаётся без подписи.
- Обе вкладки только читают данные. Событий в журнал они не пишут.

## 6. Проверка

- Разметка экрана — `engine/web/atlas.html` (фрагмент, вставляется в `#view-atlas`), стили — `engine/web/static/app.css`, логика — `app.js`, рендер — `map.js` и `graph.js`.
- `map.js`/`graph.js` подключены в `index.html`: теги `<script>` внутри фрагмента, вставленного через `innerHTML`, браузер не исполняет.
- Маршруты карты и графа закреплены `TestRouteTable` через `ROUTES.md`; тексты интерфейса проверяет `TestUITextsWithoutStationSlang`.
