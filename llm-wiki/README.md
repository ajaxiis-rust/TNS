# llm-wiki — машинная карта кода

Генерат инструмента `gograph_wiki` по статическому графу кода. Страницы:
`overview`, `architecture` (диаграмма зависимостей), `hotspots`, `env`,
`errors`, `concurrency`, `api-surface` и `packages/<пакет>` на каждый пакет.

Назначение — токен-дешёвая ориентация для агентов и быстрая сводка для
разработчиков, вторичная от кода. Это справочник, не документация проекта:
страницы пакетов — таблицы символов. Человеческая документация — `DOCS/`,
публичная вики репозитория GitHub.

Перегенерация: инструмент `gograph_wiki` MCP-сервера gograph с
`output: "llm-wiki"`; перезаписывает перечисленные страницы, этот README не
трогает. Сгенерировано 23.11.2026 по дереву после волны P17.
