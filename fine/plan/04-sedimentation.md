# P3. Оседание

Цель волны: живые сцены оседают в литературную базу — становятся заготовками банка;
оседание идёт в паузах и ночью: очистка в слоты, дедуп по смыслу, вердикт авто-критика.
Запись — только через Цензор и ниже проверенного уровня; до «проверенной» поднимает Гефест при ковке.

Гейты и рамки — см. 00-INDEX. Пути — от `TNS65/`; шелл для всех команд: `export PATH="$HOME/.local/go/bin:$PATH"`.

- **Шаги:**
  1. В `write.go` перед записью прогнать `cleaned_text` через цензора при ковке (словарная цензура по контракту языкового пакета, D-14.3); непрошедшее — отказ, строка не создаётся.

- **Проверка:** `cd engine && go test ./internal/sediment -race -run TestWrite -v` → PASS: запись через цензора создаёт строку с `trust_level=0`; выставление `trust_level=1` писателем оседания отклонено; хэндл `core` на `sediment_scene` получает `ErrForeignWriter`; `sqlite3 world_db/worlds/<slug>/literary.db "select count(*) from sediment_scene"` → `1` после одного прогона.
