# P18. Дыры зёрен: каталог, доделки, отложенные решения

Волна закрывает дыры, вскрытые аудитом зёрен (`work/SEEDS-AUDIT-20261123.md`,
MiMo, 23.11). Решение владельца 23.11.2026: «догон — оформить, остальное в
работу; это не просто механики, это дыры незакрытые». Зёрна аудита — не
фича-пожелания, а расхождения «задумка ↔ канон ↔ код», каждое либо
оформляется, либо доделывается, либо явно откладывается.

Норма данных — пак `engine/packs/ru`; код — `engine/internal`; каталог —
`DOCS/MECHANICS.md`; атомы — `fine/04-spec/`. Аудит — вход волны: у каждой
задачи в «Читать» — пути и строки из отчёта.

**Отложено владельцем (вне волны, явные решения требуются):**
- **Ход-рейт** — канон LT-10 (`fine/04-spec/04-live-turn.md`) закрыл тему в
  пользу времени 1:1 + декларации прыжка; возврат — только явной отменой
  атома владельцем.
- **8 статов тела** — конфликт с действующим D&D-набором
  (`npc_layers.go:91-99`, strength…charisma + 9 навыков + 8 пороков):
  нужна явная форма (заменить/дополнить), без неё задача не стартует.
