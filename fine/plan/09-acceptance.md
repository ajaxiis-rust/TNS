# Ф8. Приёмка

Цель волны: доказать, что станок играет целиком, а не по частям. Девять сквозных
сценариев из `fine/04-spec/09-acceptance.md` прогоняются на собранном бинарнике,
на чистом каталоге данных, с заранее известным исходом. Каждый сценарий —
отдельная задача с одной командой и одним ожидаемым результатом.

Сквозные сценарии живут в `engine/e2e/`: каждый — отдельный прогон, который сам
готовит каталог `world_db/` во временной папке, поднимает ядро, подаёт реплики и
проверяет базы. Отчёты складываются в `engine/e2e/reports/<ID>.json`, код возврата
0 — сценарий пройден. Сквозные гейты Ф0 действуют и здесь: сеть, порты, один
писатель, размерность, честный журнал.

### T-09-01. INT-1. Рождение мира целиком
- **Атомы:** INT-1, B-01, B-05, B-08, B-09, B-10.
- **Зависит от:** T-02-01…T-02-07, T-08-05.
- **Создаётся:** `engine/e2e/int1_birth.sh`, `engine/e2e/lib/harness.sh`.
- **Правится:** нет.
- **Писатель:** `ядро` — проверяет записи, сам не пишет.
- **Шаги:**
  1. Харнесс: временный каталог, `tns65 world birth --ancketa <файл>` с анкетой из 14 полей, остановка ядра после рождения.
  2. Проверить пачку: `characters` = 96, пары «психотип — сословие» уникальны.
  3. Проверить якорь: `anchor_narrative_id` непуст, ровно один; в журнале за время рождения нет ни одного вызова слота прозы.
  4. Прогнать отказ: анкета с пустым синопсисом → код 2, каталог мира не создан.
  5. Прогнать принудительный якорь: синопсис без близких нарративов → якорь всё равно назначен.
- **Проверка:** `bash engine/e2e/int1_birth.sh` → exit 0, отчёт `int1.json`: `cards=96`, `anchors=1`, `llm_calls=0`, `empty_synopsis_exit=2`, `forced_anchor=true`.
- **Исполнитель:** код.

### T-09-02. INT-2. Пауза не морозит мир
- **Атомы:** INT-2, LT-11, LT-12, LT-13, W-17, F-10.
- **Зависит от:** T-03-13, T-05-01, T-05-10.
- **Создаётся:** `engine/e2e/int2_pause.sh`.
- **Правится:** нет.
- **Писатель:** `ядро` — только чтение для проверки.
- **Шаги:**
  1. Родить мир, сыграть две реплики, поставить отложенное событие с дедлайном «сейчас + 2 игровых дня».
  2. Остановить игровые действия и сдвинуть инжектируемые часы ядра на 3 игровых дня вперёд (часы подменяются тестом, реального ожидания нет).
  3. Проверить: событие исполнено до возврата игрока, статус `fired`, запись в `events`.

  5. Проверить, что состояние мира после паузы отличается от состояния до паузы (сравнение снимков `character_state`).
- **Проверка:** `bash engine/e2e/int2_pause.sh` → exit 0, отчёт: `deferred_fired=true`, `summary_present=true`, `world_state_changed=true`, `freeze_paths=0`.

## Выход волны Ф8: релизный пакет

Девять сценариев зелёные → собирается релизный пакет одной версии (F-12.5):

1. `bash engine/scripts/build.sh` — три бинарника ядра и бинарники задач роя одной версии.
2. `gofmt -l engine` пусто, `go vet ./...` чисто, `go test ./... -race` зелено на чистом прогоне.
3. `bash engine/e2e/run_all.sh` — девять отчётов, все с кодом 0.
4. `ss -lntp` — наружных слушающих сокетов нет; порт-гейт при старте чист.
5. Пакет языкового пакета `packs/ru` с версией и контрольными суммами; запечённый `base.db` с суммой.
6. Владелец проходит один живой сценарий руками (рождение → три реплики → пауза → глава → экспорт); это единственная проверка волны, где исполнитель — владелец, и она не заменяет девять автоматических.

С этого момента станок готов к игре; дальше — только новые языковые пакеты и порт лемматизатора по решению В-1.
