# Журнал задач TNS65

Единственный источник статуса. Правило: «сделано» = зелёная проверка из задачи +
коммит + строка здесь обновлена. Отчёт словами статус не меняет.

Статусы: `todo` — не начата, `doing` — в работе, `done` — закрыта, `blocked` —
стоит на вилке владельца или на незакрытой зависимости.

Старт волны не начинается, пока в ней есть `blocked` без решения владельца.
Сквозные гейты (сеть, порты, один писатель, размерность 1024, честный журнал)
проверяются в каждой задаче и отдельно не закрываются.
