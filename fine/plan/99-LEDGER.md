# Журнал задач TNS65

Единственный источник статуса. Правило: «сделано» = зелёная проверка из задачи +
коммит + строка здесь обновлена. Отчёт словами статус не меняет.

Статусы: `todo` — не начата, `doing` — в работе, `done` — закрыта,
`blocked-owner` — стоит на незакрытой вилке владельца,
`blocked-dep` — ждёт готовности другой задачи или контура (волну не останавливает).
Переходы: `todo → doing → done`; `todo/doing → blocked-*`; `blocked-* → todo`
после устранения причины — в той же правке обновляется примечание.

Старт волны не начинается, пока в ней есть `blocked-owner`. `blocked-dep`
волну не останавливает: он виден в «Зависит от» задачи и в примечании.
Сквозные гейты (сеть, порты, один писатель, размерность 1024, честный журнал,
отказы модельных шагов) проверяются в каждой задаче командой
`cd engine && bash scripts/gates.sh` и отдельно не закрываются.
