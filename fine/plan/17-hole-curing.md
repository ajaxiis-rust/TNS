# P16. Лечение дыр: закрыть найденное

Волна лечит дыры, найденные дистилляцией: доводит термины до игрока, вливает
остаток словаря, калибрует подбор якоря, ставит колонки профиля игрока, пишет
сквозной тест мастерской, мигрирует старые записи литбазы, переписывает атом
B-03.7 под закон DEC-5 и переносумеровывает закрытые волны с псевдонимами.
Основание — предложение `work/HOLE-CURING-PROPOSAL-20261122.md`, утверждённое
владельцем 22.11.2026; развилки — раздел «(в-реш)» предложения.

Границы волны: код движка правится (в отличие от P15); канон правится точечно —
B-03.7, остаточные формулировки LT-13, описания `player_atlas`; история
неприкосновенна везде, кроме явного исключения T-17-08 (перенумерация по
решению владельца: правятся только строки идентификаторов). Не-цели: TNS75,
восстановление P14, EN-доки. Never-edit: `RAW/`, `brief3.md`, `fine/00-recon`,
датированные предложения `work/`.

База волны: main после слияния P15 (fast-forward, решение владельца 22.11);
ветка `dry/17-hole-curing`.

Порядок исполнения задаёт «Зависит от». Параллельные группы: T-17-01, T-17-02,
T-17-04, T-17-06, T-17-07 стартуют вместе (попарно не пересекаются по файлам);
T-17-03 — после T-17-02; T-17-05 — после T-17-04; T-17-08 — после правок
остальных задач; T-17-09 — живая сессия владельца.
