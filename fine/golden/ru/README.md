# Золотой отрывок ru — черновик разметки

Первый проход разметки для калибровки пайплайна разбора книг (TNS65). Владелец правит этот файл;
правки — это и есть калибровка. Разметка делалась одним проходом, поэтому спорные места помечены
`uncertain`, а не «подогнаны».

## Состав

| файл | что внутри |
|---|---|
| `excerpt.txt` | чистый текст отрывка, абзацы разделены пустой строкой, главы помечены `### ГЛАВА I…IX`. 314 абзацев, 11 064 слова |
| `golden.json` | разметка 30 чанков, 9 сцен, 23 персонажа, статистика |

Источник: Л. Н. Толстой, «Анна Каренина», часть I, главы I–IX (публичный домен), текст с
ru.wikisource.org (страницы «Анна Каренина (Толстой)/Часть I/Глава I…IX»). Локально в репозитории
связной прозы нужного объёма нет: `engine/seed/verses.txt`, `engine/seed/narratives/*.txt` и
`engine/internal/workshop/testdata/*` — до 500 слов каждый.

Чанкование: 300–500 слов (фактически 307–426, среднее 369), границы только по абзацам, реплика
диалога не рвётся (в этом тексте каждая реплика — отдельный абзац). Чанк может пересекать границу
главы; такие стыки видны по `scene` и `uncertain`.

## Схема `golden.json`

```
source, chunking            — провенанс и правило нарезки
chunks[]:
  id                        — 0..29
  para_from / para_to       — индексы абзацев в excerpt.txt, 0-based, заголовки «### ГЛАВА …» не считаются
  words                     — слов в чанке (для проверки попадания в 300–500)
  categories{9}:            — все 9 ключей присутствуют всегда
     present                — true, если intensity > 0
     intensity              — 0..1, насыщенность чанка категорией (субъективная оценка)
     anchors[]              — до 3 лемм в словарной форме (сущ. — им. п. ед. ч.; глагол — инфинитив)
  characters[{name, mentions}]
  dialogue_share            — доля слов в абзацах, начинающихся с тире (прямая речь)
  quoted_share              — доля слов в абзацах с «…», но без тире (внутренняя речь, цитаты, письма)
  scene                     — id сцены (1..9), границы консервативные
  uncertain                 — true, если разметка чанка спорна
  uncertain_reason          — только у uncertain-чанков, в чём сомнение
scenes[]                    — id, диапазон абзацев, место, участники, примечание
characters_total[]          — каноническое имя, алиасы, пояснение (в т. ч. какие роли относятся к лицу)
stats                       — чанки, сцены, персонажи, uncertain, категории-present, средний dialogue_share
```

Правила, которые надо соблюдать при правке, иначе метрики поедут:

1. **`mentions` считает только именные формы** (имя, имя-отчество, фамилия, прозвище). Ролевые слова
   («жена», «муж», «барин», «отец») и местоимения не считаются. Поэтому персонаж может отсутствовать
   в `characters` чанка, хотя действует в нём — смотри `scenes[].participants`. Если решено считать
   роли, надо переразметить весь файл, иначе счётчики несравнимы.
2. **Имя-отчество-фамилия — одно упоминание**, а не два («Степан Аркадьич Облонский» = 1).
3. **`dialogue_share` — только тире**; кавычки без тире идут в `quoted_share`. Смешивать нельзя:
   внутренний монолог в этом тексте оформлен кавычками и даёт ложный «диалог».
4. **Сцена меняется только при явной смене места/времени/состава**. Ретроспектива в том же месте
   новую сцену не открывает, но чанк помечается `uncertain`. У чанка стоит сцена его **первого**
   абзаца (чанки 20, 24, 29 пересекают стык — см. `uncertain_reason`). Сцена 9 (выход из сада,
   абзацы 299–313) не получает отдельного чанка: она целиком внутри чанка 29.
5. **`intensity` — про насыщенность, а не про наличие**: 0.2 = одна деталь на весь чанк,
   0.9 = категория держит чанк (портрет, скандал, пейзаж).

## Как этим калиброваться

- **Пороги «уверенно / спорно / брак».** Разложить `intensity` по категории: значения ≥ 0.6 — ядро
  категории (должно извлекаться всегда), 0.15–0.3 — периферия (пропуск допустим), 0 — фон.
  Пограничная полоса 0.3–0.5 на этом отрывке и есть зона, где экстрактор чаще всего расходится.
- **Сверка `present`.** precision/recall по каждой категории отдельно: ложное срабатывание дешевле
  пропуска только для appearance/emotion, для nature/time — наоборот.
- **Сверка `anchors`.** hit@3 по леммам: сколько моих якорей попало в топ-3 словаря чанка. Расхождение
  в якорях при совпавшем `present` — сигнал, что словарь категории шумит.
- **`dialogue_share`.** MAE по чанкам; проверять отдельно чанки, где `quoted_share` высок, а
  `dialogue_share` ≈ 0: грубая ошибка пайплайна — считать кавычки диалогом.
- **`scene`.** Точность границ (не номеров): сравнение множеств `para_from` разрывов.
- **`characters[].mentions`.** MAE по парам (чанк, персонаж); отдельно проверять слияние алиасов
  (Стива/Степан Аркадьич/Облонский) — это главный источник ошибок карты персонажей.
- **`uncertain` (11 из 30).** Это готовый набор спорных случаев: если экстрактор расходится с
  разметкой именно на них — это не брак, а порог. Расхождение на `uncertain: false` — брак.

## Известные перекосы отрывка

- Нет сцен природы, кроме катка (зимний пейзаж) → `nature` всего в 6 чанках, порог по ней калибровать
  на этом отрывке нельзя.
- Много служебных/бытовых сцен: `architecture` доминирует, `social` часто выражен ролевыми словами
  (барин/сударь/профессор), а не титулами.
- Длинные публицистические и философские куски (чанки 5, 22, 23) бедны действием — на них видно, как
  категория `speech` ловит косвенную и цитируемую речь.
- Один автор, один стиль, часть I: стилевая карта по этому отрывку не строится, только проверяется
  отсутствие ложных «стилевых» срабатываний.
- 23 персонажа, из них 6 существенных; редкие (Марья, Калинина) нужны как проверка на спам
  эпизодических имён.
