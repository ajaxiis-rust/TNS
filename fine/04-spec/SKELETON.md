# SKELETON — спецификация v2 (04-spec), атомы по подсистемам

Рабочий документ конвейера. НЕ спека: здесь допустимы указатели на источники.
Спека = файлы `NN-*.md` в этой папке; в их тексте провенанс запрещён.

## Формат атома (обязателен для каждого)

```
### <ID>. <Название>
Суть: 1–2 фразы нормы.
Правила: нумерованные требования (механика, границы, запреты).
Данные: таблицы/поля/файлы — если есть.
Связи: только ID атомов.
Приёмка: механически проверяемый критерий (команда/файл/поведение).
```

Правила текста спеки: русский; роли-сущности с заглавной (Пила, Ткач, Челнок,
Селектор, Цензор, Редактор, Труппа, Паганель, Гефест, Пифия; Толмач —
историческая); движок/станок/кузница строчными; дайджест —
термин игрока, сводка — термин мастерской; без дат, без «решение владельца»,
без R-ссылок, без «ТРЕБУЕТСЯ ДИЗАЙН», без AMBIG. Числа (пороги, таймеры,
размерности) живут в атомах.

## Пометки скелета

- [В] — закрыто решением владельца (17–18.10), вшивается как норма.
- [Д] — дефолт, вшитый архитектором для вето владельца; при молчании — норма.
- «Источники» в конце файла — для писателя, в спеку не переносится.

- GLO-2 Роли-сущности с заглавной; движок/станок/кузница строчными; исключения «текстовый редактор», «режим редактора».
- GLO-3 Запреты словоупотребления (по словарю).
- GLO-4 Приоритет источников: канон п.N > спецификация > план > interface-банк.
- GLO-5 Правило исполнителя: каждый гейт называет исполнителя (код/модель), владелец вне операционного цикла.
- GLO-6 Критерий успеха любой фичи.
- [Д] Рабочие числа в глоссарии не живут — только в атомах; машиночитаемый реестр терминов не заводится, файл один.

## 01-data.md — слой данных (D)

- D-01 Три базы: состав, размещение (папка движка / папка мира), жизненный цикл.
- D-02 base.db: базовые нарративы книги; гранулярность = целый сюжет, один вектор с резюме дуги [В AMBIG-3].
- D-03 base.db: векторы посчитаны один раз при сборке движка, после сборки база заморожена; для живого хода read-only.
- D-04 Запекание сида (библии): внеигровой инструмент предстартовой подготовки; контуры игры получают уже запечённое; не путать с «запеканием» мастерской [В 17.10].
- D-05 literary.db: точечные заготовки мира (имена, время, стиль, нюансы драматургии).
- D-06 literary.db: пишут Гефест/Forge и оседание; читает ход.
- D-07 world(name).db: оперативная база мира, рождается вместе с миром, наполняют игрок и движок.
- D-08 world(name).db: в ней вся игра и пачка персонажей.
- D-09 Права на базы: base.db — только разработчик; literary.db — Гефест/Forge; мир — игра.
- D-10 Унаследованные контракты TNS35: наследование указателями, не копией.
- D-11 Языковой пакет: состав — лемматизатор, лексикон намерений, запрет-списки, словарные детекторы времени и настроения.
- D-12 Языковой пакет на диске: каталог + манифест + версия; анкета рождения ссылается на выбранный пакет [Д].
- D-13 Лемматизатор русского пакета: AlexMaxy/gomorphy; контракт stdio/JSON (лемма, часть речи, метки); отрицание — отдельной леммой «не».
- D-14 Словари пакета (лексикон, запрет-списки, детекторы): файлы пакета, а не таблицы литературной базы; контракт чтения конвейером [Д].
- D-15 Перевод базовых пулов: разовая операция сборки пакета, не роль хода; Толмач — историческая роль.
- D-16 Векторный слой: BGE-M3 на :5002; embeddingDimension = 1024 [В 17.10; UI-дефолт 384 устарел].
- D-17 Хранилище векторов: отдельная таблица векторов с метаданными; смена модели эмбеддинга = пересчёт векторов [Д].
- D-18 Память NPC: halfLifeDays, similarityThreshold, maxMemoryEntries (канон п.8).
- D-19 Схемы БД: наследование аддитивное (унаследованные таблицы как есть + новые); точный DDL — план разработки, не спека [Д].

Источники: R-009, R-012, R-013, R-034, R-125, R-133, R-137–R-140, R-154 (STALE), AMBIG-3/4, решения 17.10 (библия/запекание, 1024).

## 02-models.md — модельный слой (MD)

- MD-01 Сменный слой: канон фиксирует роли и требования, имена моделей — реализация.
- MD-02 Состав слоя: лемматизатор пакета; Ткач и Редактор прозы; глубокий разбор первой реплики.
- MD-03 Текущая реализация: генерация :5001 (3B q4), эмбеддинги :5002 (BGE-M3, ~2.4 ГБ), AlexMaxy/gomorphy (~100 МБ) — заменяемо без правки норм.
- MD-04 Слоты Ткача и глубокого разбора: локальная модель или внешний API по явному выбору; настройка в UI.
- MD-05 Три заводских пресета («локально — слабая машина», «локально — средняя», «внешние API»); дефолт локальный.
- MD-06 Деградация: внешний слот недоступен → локальная запаска; ход доставляется всегда.
- MD-07 Запаска при пресете «внешние API» — тот же станок :5001 [Д].
- MD-08 Менеджер моделей: установка/замена, прогресс загрузки, целостность, откат; раздел вкладки «Настройки».
- MD-09 Загрузка моделей: HF напрямую, только исходящие соединения; каталог world_db/models/; загрузка по явному запросу, не автономно.
- MD-10 Версии языкового пакета — по образцу менеджера моделей (упаковка, версии, целостность, откат).
- MD-11 Требование к любой конфигурации слотов: повторяемость записей банка; страховка от недоступности слота; независимость словарного контроля от слота.

Источники: R-008–R-011, R-029, R-080, R-102, R-159.

## 03-birth.md — рождение мира (B)

- B-01 Анкета рождения: 14 полей со слагом — слаг мира латиницей (техническое) + 13 смысловых: Заголовок, Описание мира, Синопсис, Пролог, Язык мира, Режим походов (реальный/вымышленный/смешанный — явно, не из жанров), Жанры (10 канонических), Правила мира, Строй (11), Экономика (4 модификатора), Магия, Рождение героя, Цензура 16+/18+ [В 17.10].
- B-02 Потребитель каждого поля назван: пролог подаётся при старте книги; isekai переключает режим переигровки; рейтинг цензуры отбирает слоты и накладывается на цензуру; по остальным полям — из реестра [Д по трём, остальное источник].
- B-03 Рождение: анкета → пачка → якорь; мастерская сразу обращается к внешним моделям (анализ и план ковки).
- B-04 Готовая проза живого хода при рождении НЕ генерируется — иначе предзаписанный сценарий с первой главы.
- B-05 Пачка: 16 психотипов × 6 сословий = 96 карточек под строй и экономику; сословия: военный/служащий, купец, аристократ, духовенство, ремесленник, крестьянин [В 17.10].
- B-06 Психотипная модель: 4 оси (E/I, N/S, T/F, J/P); 14 хранимых метрик профиля; 16 кодов типов = пространство, не перечень; 12 нарративных архетипов Юнга — отдельный этаж для лиц.
- B-07 Слои данных NPC: состояние (здоровье 0–100, настроение, 9 навыков, память); экономика (6 статов, 8 пороков, темперамент 4 гумора, лояльность, семья); скрытый l3 (психотип Юнга + тайные мотивы) — сосуществуют по конструкции.
- B-08 Якорь при рождении: ближайший к синопсису нарратив по векторам, без LLM.
- B-09 Пустой синопсис: анкета не проходит валидацию, рождение не выполняется [В 18.10].
- B-10 Нет близкого нарратива: берётся ближайший принудительно, якорь есть всегда [В 18.10].
- B-11 Isekai = переигровка в том же мире; прошлое остаётся в истории мира (мир-помнит).
- B-12 Доукомплектация персонажей: Forge достраивает карточки в паузу (ступень 3).
- B-13 Признак заказа доукомплектации: элемент очереди мастерской с типом заказа; снимается при исчезновении спроса [Д].
- B-14 Локальный пресет при рождении: анализ и план ковки выполняет локальный слот (деградированно, но выполняются) [Д].

Источники: R-022–R-028, R-040, R-125–R-136, поиски Q1–Q3, AMBIG-1/2/5/8, решения 17.10.

## 04-live-turn.md — живой ход (LT)

- LT-01 Конвейер реплики: шаги от реплики игрока до стримингового ответа (канон п.9).
- LT-02 Реплика режется на предложения; лемматизация и векторизация — мгновенно.
- LT-03 Предварительный путь: гипотеза намерения лексиконом пакета.
- LT-04 Двухголосие подтверждения: леммы главнее, вектор — второе мнение.
- LT-05 Селектор — единственный судья: Челнок из банка (рутина) или Ткач (проза).
- LT-06 Стриминговая подкладка ответа.
- LT-07 Стоп-кран: неподтверждённое в мир не пишется.
- LT-08 Банк рутины: повторяемое выдаётся одинаково; ответ за секунды; без внешнего вызова.
- LT-09 Пила: настроение игрока, нити связей, диспетчер глубины, пик сцены (канон п.6).
- LT-10 Время 1:1: мир не убегает; скачок только декларацией игрока; до суток — мгновенно с просчётом ближнего круга; дольше — заказ в мастерскую; молчание > 8 ч = ночь; прыжок не пустой.
- LT-11 Пауза ≠ заморозка: в отсутствие игрока мир живёт той же скоростью; возврат = сводка «пока тебя не было» + запаздывающие вести; реализация пауз заморозкой запрещена [В AMBIG-9].
- LT-12 Состав обсчётов NPC в паузе: кодовые векторы судьбы + срабатывание отложенных событий; без LLM [Д].
- LT-13 Разделение сводки и вести: сводка формируется при возврате, если сработало отложенное событие или отсутствие превысило порог ночи; остальное — запаздывающие вести [Д].
- LT-14 Порог тишины Ткача = 60 секунд [В]; действует и для деградировавшей запаски [Д].
- LT-15 Слеш-команды: дополнение к прозе, не замена.
- LT-16 Труппа: персонаж рождается в ходе без истории, копит память реакций; ружьё (канон п.12).
- LT-17 Сдвиг положения героя событием: код применяет сдвиг; точность не требуется, достаточно для срабатываний; пишется одной транзакцией с ответом [Д по транзакции].

Источники: R-018, R-029–R-037, R-057, AMBIG-7/9.

## 05-workshop.md — мастерская (W)

- W-01 Мастерская = фоновая работа пауз и ночи (канон п.7).
- W-02 Варка по релевантности в паузах.
- W-03 Оседание: очистка удачных сцен от фактов, дедуп по смыслу, запись в literary.db (канон п.10).
- W-04 Сигналы лайк/дизлайк игрока; префильтр конвейера оседания у Паганеля.
- W-05 Паганель: фоновая ковка карты (канон п.16).
- W-06 Гео-модель: места и пути хранят реальные координаты + коэффициент трения по типу пути (тракт/река/море); дни в пути вычисляются на лету; норма дня мира 20–30 км пешком (параметр мира/эпохи); дни никогда не хранятся.
- W-07 Калибровка расстояний: выдуманный мир — слово игрока первично («две недели пути» = обязывающее); реальный — координаты газетира; смешанный — реальный холст + книжные точки, не сдвигаются.
- W-08 Положение игрока в живом ходе: приблизительное, достаточно для срабатываний; событие (буря и т.п.) сдвигает его кодом.
- W-09 Кольца Паганеля: очередь/текущая работа/прогресс; журнал колец живёт во вкладке MCP.
- W-10 Разведка наружу: норма, с разрешения и тайм-аутом; бюджет сессии ~3 вызова.
- W-11 Достройка кольца/коридора: отдельный бюджет фоновой задачи, не делит лимит сессии разведки [Д].
- W-12 Пифия: карта игрока-атлас копится ночами (психотип, настроение, интересы) (канон п.17).
- W-13 Гороскоп-выпуск под сцену: ветки ответа, прогноз Пилы, темы варки; три ограждения: совет не приговор, стоп-кран, провалился — не форсировать.
- W-14 Гефест/кузница: каркас TNS35 целиком; вход txt/fb2; Цензор при варке (канон п.18).
- W-15 Редактор: правки орфографии/пунктуации; непрошедшее Цензора бракуется автоматически.
- W-16 Очередь редактуры: разбирает код; Редактор запускается по закрытию главы [Д].
- W-17 Отложенные события: хранятся в world(name).db; исполнитель срабатывания — код таймера движка [Д].

Источники: R-038–R-055, R-061, R-063, R-134, R-165, канон:350.
