ФОРМАТ КАЖДОГО АТОМА (строго, поля идут в этом порядке):
### <ID>. <Название>
Суть: 1–2 фразы нормы.
Правила: нумерованные требования (механика, границы, запреты) — каждое с новой строки «1.» «2.» …
Данные: таблицы/поля/файлы — только если есть что сказать; иначе строку опусти.
Связи: только ID других атомов; если связей нет — строку опусти.
Приёмка: механически проверяемый критерий (команда/файл/поведение).
