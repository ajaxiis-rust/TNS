# TNS65 — Словарь терминов

Правило (наследие словарика владельца): в документах и разговоре — только эти точные термины; выдуманные слова и метафоры для технических состояний запрещены; новый термин вносится сюда, а не в текст мимо словаря. Определения держатся языка владельца.

Схема записи: термин (не больше двух слов, замороженные составные — целиком) — суть одним предложением — кодовый идентификатор — запрещённые синонимы — ссылка на пункт канона. Машиночитаемая таблица `dev/GLOSSARY-TERMS.tsv` генерируется из этого файла и двух других якорей (`dev/GLOSSARY.md`, `fine/04-spec/00-glossary.md`): `cd engine && bash scripts/glossary-terms.sh`; руками таблица не правится.
